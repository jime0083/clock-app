### 26.6.1 窓判定の純粋関数モジュール（新規 src/services/alarmWindow.ts）[完了 2026-07-06]
- [x] `SQUAT_WINDOW_MS = 5 * 60 * 1000` を定義・export（alarmService.ts のローカル定数はここからのimportに置換）
- [x] `interface AlarmWindowState { alarmTime: string | null; alarmDays: number[]; lastAlarmSentAt: number | null; squatCompletedAt: number | null; alarmFailedAt: number | null }`（時刻は全て epoch ms）
- [x] `extractAlarmWindowState(data): AlarmWindowState` — Firestoreドキュメントデータから変換。settings.alarmTime / settings.alarmDays を読み、タイムスタンプは Firestore Timestamp（toMillis duck-typing）と ISO文字列の両対応
- [x] `evaluateAlarmWindow(state, nowMs): boolean` — 以下のロジック:
  1. スケジュール候補: alarmTime が "H:mm"/"HH:mm" 形式なら、今日と昨日（深夜跨ぎ用）の端末ローカル発生時刻を計算。`発生時刻 <= now かつ now - 発生時刻 <= SQUAT_WINDOW_MS` かつ 曜日が alarmDays に含まれる（空配列=毎日）ものを候補に追加
